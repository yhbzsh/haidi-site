个人介绍

你好，我是海底。我的技术路线是从一个很具体的问题开始的：给自己搭一个能长期维护的网站。 为此学了 HTML/CSS、域名和服务器，后来发现真正花时间的是数据与模型，于是转向 Python。

我做项目的方式比较固定：先把问题定义清楚，再决定数据、方法和评估标准；实现之后保留代码、结果和失败案例。 比起跑通一个 demo，更在意它能否复现、能否解释。

这个站是这套方法的记录：前台重写过一次，后台是一个用 Python 标准库写的零依赖 CMS，服务器与 HTTPS 也自己维护。

目前关注数据分析、Web 后端与深度学习应用，也在补计算机基础和工程化。如果某篇文章或实现对你有用，欢迎来信讨论。

学习路径

  1. 基础 · Python 与数据 · 语法、pandas、matplotlib、SQL；练习聚类与文本情感分析，先把分析流程走顺。
  2. 进阶 · 完整数据流程 · 采集、清洗、建模、可视化与结论；招聘、租房、逾期预测，重点是指标和边界条件。
  3. 综合 · 系统与工程 · Django/MySQL、PyQt、Linux 与部署；漏洞扫描、人脸签到、本站，关注可维护性。
  4. 研究 · 深度学习与强化学习 · CNN、FasterRCNN、ResNet50+CBAM、DQN/PPO；汉字识别、人流检测、番茄缺陷、Mario。
